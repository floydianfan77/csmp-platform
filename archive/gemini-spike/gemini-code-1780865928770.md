## 🗺️ 1. System Topology & High-Level Architecture

The Chapecó Smart Mobility Platform (CSMP) is designed to capture, process, and analyze real-time urban traffic infrastructure data within the Chapecó municipality bounding box. It handles high-velocity spatial telemetry by decoupling real-time stateful stream processing from batch-oriented geospatial analytics warehousing.
